# 技术架构

掌间星云使用“摄像头识别线程 + 主线程状态机 + WebGL 渲染”的轻量架构。项目没有前端框架和构建步骤，所有运行文件都位于 `dist/`。

## 数据流

```text
摄像头视频
   │ createImageBitmap
   ▼
hand-worker.js
   │ MediaPipe Hand Landmarker
   │ 输出最多两只手的 21 个关键点
   ▼
gestures.js
   │ 计算手掌位置、张合程度、转角、双手间距
   │ 根据张合速度更新相对缩放状态
   ▼
app.js
   │ 管理摄像头生命周期、鼠标降级与界面状态
   ▼
particles.js
   │ 生成目标形态、插值变形、旋转和透视投影
   ▼
WebGL Canvas
```

## 模块职责

### `app.js`

- 请求和释放摄像头权限。
- 将视频帧转成可转移的 `ImageBitmap`，发送到 Worker。
- 在摄像头、鼠标与触屏输入间切换。
- 管理暂停、全屏、粒子密度、形态和配色。
- 页面进入后台时主动关闭摄像头。

### `hand-worker.js`

- 动态加载本地 MediaPipe Tasks Vision。
- 在独立线程创建 Hand Landmarker。
- 以约 15 FPS 处理视频帧，避免阻塞主线程动画。
- 只把手部关键点返回主线程，不保存图像。

### `gestures.js`

- 用腕部和掌指关节归一化手指距离，降低远近变化的影响。
- 输出手掌中心、横滚角、偏航量、张合度与双手间距。
- 单手缩放使用相对速度状态机：
  - 缓慢张开：放大；
  - 缓慢收拢：缩小；
  - 快速张合：仅更新操作起点，不改变尺寸；
  - 短暂丢失手掌：保留当前尺寸。
- 双手模式记录进入时的基准间距，以相对变化控制缩放，避免跳变。

### `particles.js`

- 生成旋涡星系、能量球和星环的三维目标点。
- 在形态切换时对粒子位置进行指数平滑插值。
- 在 CPU 侧完成旋转、深度和透视参数计算，并批量上传 WebGL 缓冲区。
- 使用点精灵和片元着色器绘制柔和发光粒子。

## 性能策略

- 手势推理限频，与屏幕刷新率解耦。
- 使用 Worker 避免推理阻塞 UI。
- 通过 `ImageBitmap` 转移所有权，减少视频帧复制。
- 页面隐藏、动画暂停或视频帧未变化时不提交推理。
- 粒子数组预分配并复用，降低垃圾回收抖动。
- 根据设备像素比限制画布分辨率，兼顾清晰度与性能。

## 隐私边界

摄像头帧只在页面与同源 Worker 之间流转。项目没有视频上传接口，也没有外部分析脚本。MediaPipe 运行库、WASM 与模型下载到 `dist/vendor` 后，可以完全离线执行识别。

## 扩展方向

- 增加更多程序化粒子形态。
- 为快慢手势阈值提供可视化校准。
- 添加低性能设备的自动粒子数量调节。
- 支持录制不包含摄像头画面的粒子动画。
